# Repository Rules

- Keep one issue per branch; name branches `<type>/<asl-slice>`.
- Never commit or push to `main`; do not push directly to `main`.
- Avoid unrelated refactors. Reproduce a problem before fixing it.
- Report evidence with the commands used and their results.
- Use imperative commit messages of at most 72 characters.
- Keep one agent active in the checkout at a time.
- Follow [WORKFLOW.md](WORKFLOW.md) and [CONTRIBUTING.md](CONTRIBUTING.md) for the detailed project workflow and contribution guidance.
